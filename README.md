# webFacile — Studio Web & Automation (WordPress / Spectra)

> **Candidat / Développeur :** Olga Popova   
> **Repository :** [`tilopa0/webfacile`](https://github.com/tilopa0/webfacile)   
> **Environnement de développement :** LocalWP / WordPress 6.x / Vercel   

---

## 📌 Présentation du Projet

**webFacile** est un studio web premium spécialisé dans le développement WordPress, les interfaces Spectra, la préparation à l'intégration d'outils IA et l'automatisation des premiers contacts clients .

Ce projet synthétise l'ensemble des compétences du référentiel Simplon (RS5599, blocs C1 à C8) .

---

## 🚀 Objectifs & Impact

* **Automatisation & Qualification :** Formulaires optimisés pour la collecte de briefs, la qualification rapide des besoins et le calcul de devis .
* **Performance optimale :** Temps de chargement inférieur à 1 seconde (images WebP, lazy loading, LiteSpeed Cache).
* **Expérience Mobile-First :** Ergonomie conçue pour les smartphones (70% du trafic cible).
* **Conformité & Sécurité :** Respect des normes WCAG, conformité RGPD (bannière Complianz, CNIL) et sécurisation Cloudflare / SSL.

---

## 🛠️ Stack Technique & Infrastructure

* **CMS & Builder :** WordPress, Spectra Blocks .
* **Direction Visuelle :** Palette Minimaliste Premium (Fond `#F9F9FB`, Titres `#2B1A12`, Texte `#3D2A21`), Typographies *Inter / SF Pro / Montserrat*.
* **Extensions clés :** Spectra, Complianz (RGPD), WPForms, Yoast SEO, LiteSpeed Cache .
* **Déploiement & Cloud :** LocalWP, GitHub, Vercel, Cloudflare DNS / SSL .
* **Automatisation :** Script local `sync.bat` (Sauvegarde OneDrive + Commit Git + Push GitHub + Déploiement Vercel) .

## 📁 Structure du Site (4 Pages)

1. **PAGE 1 — ACCUEIL :** Hero premium, démonstration/concept IA, architecture technique, FAQ, performance & sécurité .
